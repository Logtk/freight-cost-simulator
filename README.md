# Freight_cost_simulator — 運送採算カルテ

運送にかかる原価を、燃料費・人件費・車両費・安全確保費といった要素から積み上げて計算し、それを毎月の採算管理につなげる分析ツールです。合成データによるポートフォリオ作品です。

## これは何のためのツールか

運送を担当する部署が売上の責任を持ちながら、実際に車を手配する部署は別、という組織はよくあります。この場合、「運賃が安いのか」「車の積載効率が低いのか」「荷待ちなどで拘束時間が長くなっているのか」「ドライバーによって燃費が違うのか」——原価が悪化している理由が見えないと、「利益が悪い」とは分かっても「だから何をすべきか」を決められません。

このツールは、原価が悪化する4つのパターンを分解して見せることで、次にとるべき打ち手（運賃交渉・配車の見直し・荷待ち削減・ドライバー教育）を判断できるようにします。同種のツールの多くは自社で車を持つ運送会社向けに作られていますが、本ツールは**車を持たない側（荷主から運送業務を引き受ける立場）の採算を可視化する**点が特徴です。

## できること

- 毎月のコース別・車両別・ドライバー別の採算を、掘り下げながら確認できる「月次採算カルテ」
- 燃料価格や人件費が上がったとき、利益がどれだけ・どこに影響するかを試算できる「感度分析」
- 顧客ごとの売上規模と採算性を一覧できる「経営レポート」
- 運賃交渉が必要な顧客を優先順位付きでリストアップする「交渉管理」
- 車種・距離・拘束時間などを入力し、単発で原価を計算できる「運賃判断」

## わかったこと

- 「売上と運賃しか見えない」状態で赤字の原因を当てようとすると、的中率は五分五分（50.0%）程度でした。原価の内訳（燃料・拘束時間・燃費など）まで見えるようにすると、的中率は9割以上（91.7%）まで上がります。この差そのものが、原価を「見える化」する価値になっています。
- 実務では複数の荷主の荷物をまとめて運びながら、荷主にはそれぞれ貸し切り分の運賃を請求しているケースがあります。この場合、「車にどれだけ荷物が積まれているか（荷主から見える指標）」と「1台あたり何件の荷物をまとめられているか（運送会社側だけが見える指標）」は別物で、両者にズレが生まれます。合成データでは、荷主からは効率が悪く見えるコースほど、実は運送会社の利益に貢献しているという結果が出ました。

## セットアップ（初回のみ）

```bash
pip install -r requirements.txt
```

合成データを生成してDBへ投入します（18ヶ月・約9,100運行分）:

```bash
python -m src.synth.load_to_db
```

## 起動

**2回目以降は`start_app.bat`をダブルクリックするだけです**（既定のブラウザが自動で開きます）。停止はウィンドウを閉じるか`Ctrl+C`。

ターミナルから起動する場合:

```bash
streamlit run app.py
```

テスト（70件。実DBファイルには触れずインメモリのみ使用）:

```bash
python -m pytest tests/ -v
```

## 使い方（タブ構成）

- **月次採算カルテ** — 粗利の月次推移、コース別サマリー（稼働率含む）、コース→車両→ドライバー→個別運行と掘り下げるドリルダウン、車両・ドライバー別の全社ランキング
- **見えている世界 / 見えていない世界** — 情報の見え方によって、赤字原因の当てやすさがどう変わるかを比較
- **荷主目線 × 業者目線** — 積載効率と集約件数のズレを可視化し、双方の見え方の違いから交渉の余地を探る
- **感度分析** — 燃料単価・人件費の変動や、値上げ・積載効率改善の効果を試算。全社への影響度、コース別の損益分岐点も確認可能
- **経営レポート** — 部署の月次損益、顧客ごとの採算ポジション、特定顧客への依存度、貨物の価値と運賃のバランス
- **交渉管理** — 運賃交渉の候補リスト（優先度順）、ステータス管理、自社標準単価表
- **運賃判断** — 単発の原価計算（車種・走行距離・拘束時間・高速代などを入力）
- **計算履歴** — 運賃判断の記録一覧

## データについて（重要）

**実データ・実企業名・実運賃・実車番・実ドライバー名は一切使用していません。** 車種別燃費・減価償却額、燃料単価・人件費単価・目標利益率、コース名、運賃額はすべて仮置きの合成値であり、実績とは無関係です。

参考にした一次情報の出典（数値そのものは合成）:

- 燃料単価: 資源エネルギー庁の燃料価格調査
- 人件費単価: 賃金構造基本統計調査（トラックドライバー職種）
- 積算要素の構成: 国土交通省「標準的運賃」「適正運賃」の考え方

匿名化の方針は [docs/design.md](docs/design.md) §6 に定義しています。
